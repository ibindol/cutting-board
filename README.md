# 도마 (Cutting Board)

크기·두께, 나무 종류, 테마를 고르면 도마 디자인 시안을 만들어 주는 무료 웹사이트입니다.

- 접속 주소: https://ibindol.github.io/cutting-board/
- 나무 11종: 느티나무, 송판, 월넛, 메이플, 티크, 올리브, 편백, 은행나무, 캄포, 아카시아, 고무나무
- 테마 4종: 트렌드, 동물, 사람, 도형 (테마마다 시안 4개 자동 생성)
- 다운로드: 시안 이미지(PNG, 사양표 포함), 디자인 파일(SVG), 레이저 각인용 실제 mm 크기 SVG

## 파일 구성
- `index.html` : 실제 웹사이트 (GitHub Pages가 이 파일을 보여줌)
- `src/page.html` : 사이트 원본. 수정 후 `sh build.sh` 를 실행하면 `index.html` 이 다시 만들어짐
